  OEssentials — Version 7.1.4
  Minecraft 1.21 | Paper / Folia
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Important Fixes
---------------
- Fixed OEssentials disabling itself completely when PacketEvents is not
  installed. The custom tab list (layout-mode: CUSTOM) and custom nametags
  now start without PacketEvents and fall back to the regular Bukkit API.
  Install PacketEvents for the full packet-based tab layout and smooth
  nametag movement.
- Fixed disabled features deleting vanilla and other plugins' commands.
  Turning a feature off in settings.yml used to remove every command with
  the same name from the whole server: for example bossbar: false removed
  vanilla /bossbar, and scoreboard: false removed vanilla /scoreboard.
  Other plugins' /hologram, /kit, /kits, /rtp, /wild, /trade and
  /maintenance could also disappear. Only OEssentials' own commands are
  removed now.

More Reliable Startup
---------------------
- A feature that fails to start no longer takes the whole plugin down.
  Tab, scoreboard, boss bar, holograms, nametags, skins, integrations,
  Discord integration, web panel, playtime, RTP, group RTP, jump pads,
  player vaults, clear lag and mobs are now optional: if one of them
  fails, it is switched off and everything else keeps running.
- The startup banner now shows modules that failed with a red cross, and
  the console prints the reason, e.g.
  "Module 'tab' is unavailable: <reason>".

Command Toggles (commands-toggle.yml)
-------------------------------------
- enabled: false now removes OEssentials' version of a command completely:
  its name, aliases, /oessentials:<command>, tab completion and its /help
  entry.
- If OEssentials had replaced a vanilla or another plugin's command with
  the same name (for example /tp or /spawn), that original command works
  again when you disable OEssentials' version. Re-enabling it switches back.
- Commands that are disabled at startup are no longer registered at all,
  so they never take a command name away from another plugin.
- Vanilla-named commands such as tp, ban, kick, gamemode, clear, msg,
  enchant, kill and bossbar can now be safely toggled. Add them to
  commands-toggle.yml to hand them back to vanilla.
- The "This command is currently disabled" message only appears when no
  other plugin provides that command.

settings.yml Switches
---------------------
Every switch in settings.yml was checked. These now fully turn their
feature off:
- shop: the switch was ignored (the shop stayed on); it now works.
  The old top-level shop.enabled is still accepted.
- help: the switch was ignored; /help is now removed when off.
- playerwarps: the switch was ignored; /pw and /pwwhitelist are now
  removed when off.
- home: only /home respected it; /sethome, /delhome, /homes, /homesgui,
  /otherhome and /otherhomes are now removed too.
- playervaults: /vaults is now removed when off.
- mobs: only health bars respected it; /spawnmob, /killallr and
  /killallrlog are now removed too.
- jumppads and portals: their listeners and commands no longer run
  when off.
- playtime-rewards: /prewards is now removed when off (/playtime and
  playtime tracking stay available).
- chat: channel commands (/channels, /channel, /channelannounce) are no
  longer registered when chat is off.
- rtp: its join listener no longer runs when off.
- maintenance: the switch now works in both places it can be written,
  maintenance.enabled and features.maintenance.enabled.

Note: settings.yml switches apply after a server restart. Command toggles
apply immediately.

Internal
--------
- Updated the bundled MinecraftModulith library to 0.5.0 (optional modules
  and ordering-only module dependencies).
