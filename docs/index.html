Next.js Preview Launcher

The premium OreoEssentials site is no longer this static file.

This folder now contains a modern Next.js + TypeScript + Tailwind + Framer Motion frontend. To see the redesigned version with animations, gradients, glassmorphism, and responsive layout, start the local dev server and open the preview URL.

Start Command

Run this from C:\Users\PC\Desktop\OreoEssentials-\docs:

npm run dev:site
Open Preview

One-Click Launcher

You can also start the preview by double-clicking the Windows launcher in this folder:

start-site.bat
Open Legacy Source Page
The old standalone HTML documentation pages have been moved into the legacy/ folder so the new frontend is the main entry point.
