currency-config.yml â€” Explained Line by Line

    min-amount: 0.01         # Smallest amount a player can send to another player.

Storage: JSON vs MongoDB

JSON Storage (Default â€” Easiest)

currency:
  storage: json
  • Data is saved to plain text files on your server disk.
  • Requires zero extra setup â€” it just works out of the box.
  • Only works on a single server. If you run multiple servers (a network), each server would have its own separate balance files â€” players' balances wouldn't carry over.
  • Files: plugins/OreoEssentials/currencies.json and currency_balances.json
Tip

If you run a single Minecraft server (not a BungeeCord/Velocity network), JSON is the right choice. Keep it simple!

MongoDB Storage

currency:
  storage: mongodb
  • Data is saved to your MongoDB database (uses the same connection already configured in OreoEssentials' main config.yml).
  • Required if you want cross-server balance sync.
  • MongoDB must already be set up and working in your main OreoEssentials config.
Warning

If you switch from json to mongodb after players have already earned balances, their old JSON balances will NOT be automatically migrated. Back up your currency_balances.json first!

Cross-Server Setup

Cross-server currency sync lets players on Server A send currency to players on Server B, and balances are shared across all servers in your network.

Requirements (all 3 must be true)

  1. OreoEssentials is installed on all servers in the network
  2. MongoDB is configured and working in OreoEssentials' main config
  3. RabbitMQ is configured and working in OreoEssentials' main config

How to Enable

currency:
  storage: mongodb     # MUST be mongodb for cross-server
  cross-server: true  # Enable cross-server balance sync
How it works

When a balance changes on any server, a RabbitMQ packet is broadcast to all other servers. They refresh their local cache from MongoDB. Currency creation/deletion is also broadcast instantly â€” create a currency on Server A and it appears on Server B within seconds.

Common Mistake

Setting cross-server: true but leaving storage: json does nothing â€” cross-server is silently disabled when storage is not MongoDB. You MUST use storage: mongodb.

Creating Currencies

There are two ways to create currencies: via command (recommended for beginners) or via the GUI.

Via Command

/oecurrency create <id> <name> <symbol> [tradeable] [defaultBalance]
  • <id> â€” A unique internal name, lowercase, no spaces. Example: gems, blood_points, credits
  • <name> â€” The display name shown to players. Example: Gems, Credits
  • <symbol> â€” A symbol or emoji shown next to amounts. Example: ðŸ’Ž, $, â˜…, BP
  • [tradeable] â€” Optional. true = players can send it to others. false = non-transferable. Default: true
  • [defaultBalance] â€” Optional. How much new players start with. Default: 0

Examples

# Create a Gems currency with ðŸ’Ž symbol
/oecurrency create gems Gems ðŸ’Ž

# Create a Blood Points currency, NOT tradeable (can't send to others)
/oecurrency create bp BloodPoints ðŸ©¸ false

# Create Credits that everyone starts with 500 of
/oecurrency create credits Credits â˜… true 500

# Create a simple dollar currency
/oecurrency create money Money $ true 0
Currency ID Rules

The ID is how the system identifies the currency internally. Rules:
â€” Must be lowercase (the plugin forces it automatically)
â€” No spaces (use underscores: blood_points)
â€” Must be unique â€” you can't have two currencies with the same ID
â€” Used in all commands: /csend Steve gems 100, /ctop gems, etc.

Deleting a Currency

/oecurrency delete <id>

# Example:
/oecurrency delete gems
Careful!

Deleting a currency removes ALL player balances for that currency too. There is no undo. Make sure you want to do this before confirming.

FAQ / Troubleshooting

Q: I created a currency but players start with 0 even though I set a default balance. Why?

The default balance only applies to players who have never had a balance recorded for that currency. If a player logged in before you changed the default, their stored balance (0) takes priority. Use /oecurrency set <player> <currency> <amount> to update existing players.

Q: I set cross-server to true but balances aren't syncing.

Check these things in order:

  1. Is storage: mongodb set? (Cross-server is silently disabled if you use json)
  2. Is MongoDB connected and working? Check your server console for MongoDB errors.
  3. Is RabbitMQ configured and connected? Check for RabbitMQ connection errors in the console.
  4. Is OreoEssentials installed on ALL servers in your network?

Q: /csend says "Currency not tradeable!" but I set tradeable to true.

The tradeable flag is set when you create the currency via command. If you created it before adding tradeable: true, you'll need to delete and recreate it, or edit it via the Admin GUI (/cadmin).

Q: A player says they sent currency but the recipient didn't receive it.

Check the server console â€” look for lines starting with [Currency]. Successful transfers log: [Currency] PlayerA sent ðŸ’Ž 100.00 to PlayerB. If you see a transfer log but the recipient is complaining, it's likely they were on another server and the notification message didn't reach them (their balance IS correct â€” they can verify with /cbal).

Q: How do I reload the config without restarting?

/oecurrency reload

This reloads currency-config.yml (messages, transfer limits, etc.). It does NOT reload currency definitions â€” those are stored in the database/JSON files and always loaded fresh.

Q: Can a currency go negative (debt system)?

Yes! When creating a currency, the allowNegative flag exists in the storage data. Currently this is set via the GUI or direct database edit. When enabled, players can go below 0 (useful for a debt/loan system). By default, balances are clamped to 0 minimum.

Q: My /ctop shows "Unknown" for some players. Why?

The leaderboard resolves player names from: PlayerDirectory (MongoDB) â†’ Bukkit's offline player cache. If a player has never joined your specific server (only played on other servers in the network) and PlayerDirectory isn't set up, their name won't be resolvable and shows as "Unknown (xxxxxxxx)". This is a display-only issue â€” their balance is tracked correctly.

Q: I deleted a currency by accident. Can I restore it?

If you use JSON storage: check if you have a backup of currency_balances.json and currencies.json. If not, the data is gone. Going forward, consider keeping backups! If you use MongoDB: you might be able to recover from a database backup. The collections used are currencies and currency_balances.

Q: PlaceholderAPI placeholders show "Invalid Currency".

This means the currency ID you put in the placeholder doesn't exist. Double-check by running /oecurrency list in-game. The ID is case-sensitive in placeholders â€” use lowercase. Example: %oreocurrency_balance_gems% not %oreocurrency_balance_Gems%.
